About the data

Source: the official public job-board APIs of Greenhouse, Lever and Ashby, one request per board per day with per-host rate limits. Only metadata and derived fields are kept: title, company, department, location, remote type, salary range, dates and the job URL. Job-description text and personal data are never stored. Descriptions are read in memory only, to extract salary and remote hints.

Downloads: the monthly Parquet dataset is attached to the repository's releases; summary CSVs and the run log live in public/. Model documentation: dbt docs.

Built by Siddharth Kumar, web scraping and data engineering (siddharthkumar.com). Numbers come from daily pipeline runs; see the run log for misses and holds.
