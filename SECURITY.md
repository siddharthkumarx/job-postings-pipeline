# Security and data requests

- **Security issues:** please email hello@siddharthkumar.com instead of opening a public issue. You will get a reply within 2 working days.
- **Remove a company's postings (opt-out):** email hello@siddharthkumar.com from a company address, or open an issue with the "Data removal request" template. Postings are removed from the published data within 24 hours, and the board is dropped from future runs.
- **Personal data:** this project does not collect names, emails or phone numbers. If you ever see personal data in the published files, email hello@siddharthkumar.com and it will be removed the same day.
